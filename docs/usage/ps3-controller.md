# PS3 手柄连接

1. 在网页的网络管理中查看设备蓝牙地址。
2. 使用手柄配置工具将该地址写入 PS3 手柄。
3. 按 PS 键，等待手柄连接。

连接后，左摇杆控制前后和横移，右摇杆控制转向。方向键以 0.15 m/s 移动，□ 和 ○ 以 0.5 rad/s 左转和右转；松开按键后恢复摇杆控制。

△ 拾取，× 坐下或站起，L1／R1 左踢／右踢，L2 控制嘴部开合。短按 Start 启动控制，同时按 Start＋Select 进入休息。L3、R3 和 R2 没有控制功能。

长按 Start 5 秒切到行走＋头部控制。左摇杆控制前后和转向，右摇杆控制头部俯仰和左右转动。再长按 Start 5 秒回到普通行走，头部回中。

拾取时嘴部会自动张开并闭合；操作 L2 可随时改为手动控制。
